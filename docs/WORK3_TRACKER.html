C1
Per-atom HIPAA decomposition. First systematic atomisation of a healthcare standard — reduces compliance verification to binary entailment a local model can execute.
C2
NA-bias annotation finding. Human annotators systematically over-label "Not Addressed"; existing compliance benchmarks inherit this bias.
C3
Local-model viability under data sovereignty. HIPAA §164.312 prohibits routing PHI through cloud APIs — the constraint is the design requirement, not a limitation.
