30 Days · 450 Hours · Three Roles

The 80/20 GenAI Engineering Mastery Roadmap

TL;DR
  • Master the 80/20 production stack first. Across 30 days × 15 hrs (450 hrs total), 80% of production GenAI value comes from six skills: LangGraph, OpenAI Responses API + Anthropic Messages API, hybrid RAG with RAGAS evaluation, MCP, LangSmith, and Microsoft Foundry. Everything else is a "nice-to-know" specialization.
  • The three roles diverge late. Days 1–20 are shared. From Day 21: 🤖 drills MCP + production patterns, 🔧 drills containers/K8s/IaC/CI-CD, 🔬 drills evaluation rigor, red-teaming, and research methodology. The final 5 days converge on a capstone.
  • Default to LangGraph + OpenAI Responses + Anthropic + MCP + LangSmith + Microsoft Foundry. Treat CrewAI, OpenAI Agents SDK, Google ADK, AutoGen, Bedrock AgentCore, and Vertex AI Agent Engine as comparative literacy — one "hello world" each, not production depth.

Roles: 🤖 GenAI/AI Engineer  ·  🔧 AI/ML Engineer  ·  🔬 Senior DS Agentic AI    MUST = top-20% skill   NICE = optional

Key Findings

01
Orchestration converged in 2025. LangGraph, CrewAI Flows, OpenAI Agents SDK, Microsoft Agent Framework, and Google ADK all settled on the same primitives: state graph + tool nodes + handoffs + interrupts + checkpointers + tracing. Learn LangGraph deeply once; the others are 1–2 day transfers.
02
The API surface converged too. OpenAI's Responses API (March 11, 2025) is now the recommended primitive with built-in tools and stateful conversations. Anthropic's Messages API adds prompt caching (cache reads at 0.1× base price — 90% reduction), extended thinking, and citations. Use LiteLLM only when you need provider-agnostic routing.
03
MCP is the new tool integration standard. Spec 2025-11-25 standardized on stdio + Streamable HTTP (SSE deprecated) with OAuth 2.1 for remote servers. Natively supported in OpenAI Responses API, Anthropic Claude, Claude Code, Cursor, and AWS Bedrock AgentCore Gateway. Building one custom MCP server is now mandatory literacy.
04
Observability has three viable options. LangSmith (best LangGraph DX, vendor-locked), Langfuse (open-source, ClickHouse-backed, OpenTelemetry-native), Arize Phoenix (single-Docker self-host, native RAGAS integration). LangSmith + Langfuse/Phoenix as fallback is the common production pattern.
05
RAG breaks predictably in five ways. Bad chunking, embedding mismatch, lost-in-the-middle, multi-hop failures, stale data. Hybrid search (BM25 + dense + Cohere/Voyage/Jina reranker) + RAGAS-driven eval-loop development fixes ~80% of cases without expensive architecture changes.
06
Microsoft Foundry is the new umbrella. Rebranded from Azure AI Foundry at Ignite, November 18, 2025. Foundry Agent Service runs containerized hosted agents on Azure Container Apps. Azure AI Search was rebranded Foundry IQ — the hybrid + semantic ranker API is unchanged.
07
AWS Bedrock AgentCore (preview, 2025) offers 8 primitives — Runtime (dedicated microVM, up to 8 hrs), Memory, Identity, Gateway, Browser, Code Interpreter, Observability, Evaluations — and is framework-agnostic. AgentCore Gateway is a managed MCP server.
08
Google Vertex AI Agent Engine is the managed runtime for ADK agents, with built-in VertexAiSessionService for multi-turn memory. Transitioning into Gemini Enterprise Agent Platform (2026), with A2A for cross-framework communication.
09
Agentic coding tools are now production infrastructure. Claude Code (CLI + VS Code + JetBrains), Cursor (.cursor/rules .mdc with 4 activation modes), OpenAI Codex CLI, GitHub Copilot. Each persona should master Claude Code as daily driver and Cursor as IDE.
10
Beads (Steve Yegge, 2025) is the breakout "agent memory" tool — a git-native, dependency-tracking issue graph stored as JSONL that survives context compaction. Not a must-master but increasingly expected literacy.

Recommendations & Decision Thresholds

Stage 1 — Days 1–14

Ship the Day-14 mini-capstone. Stop and reassess if:

  • Day-14 median cost > $0.10/call → prompt-caching not used, revisit Day 4
  • Median latency > 8s → too many sequential LLM calls; consider parallel tool use or smaller graph
  • Eval suite < 20 cases by Day 14 → do not proceed to Phase 3
Stage 2 — Days 15–25

By Day 25 you should have: hybrid-search RAG with reranking, all three observability tools instrumented, an eval-on-PR gate, and a passing red-team suite. Stop and reassess if:

  • RAGAS faithfulness < 0.85 on golden set → revisit chunking + reranker (Day 17)
  • Cannot trace a HITL interrupt + resume end-to-end → revisit Day 22
  • Red-team injection success > 10% → add second guardrail layer (Day 24) before production
Stage 3 — Days 26–30

Default to Microsoft Foundry. Switch only if:

  • AWS-native with no Azure footprint → Bedrock + AgentCore + Lambda/ECS/EKS + OpenSearch Serverless
  • GCP-native or Gemini-grounding dependency → Vertex AI Agent Engine + ADK + Cloud Run/GKE/AlloyDB
Post-Day-30 Specialization
  • 🤖 Ship a public MCP server registry contribution; build 2 more production agent apps; learn one new framework quarterly
  • 🔧 Add fine-tuning track (LoRA/QLoRA on a 7B model); pursue AI-102 (Azure), AWS ML Specialty, or Google Professional ML Engineer
  • 🔬 Publish an internal eval framework; read 2 papers/day; double LangGraph practice
  • If you cannot build Day-14 capstone solo, repeat Days 7–9 before Phase 3
  • If you skip the eval suite (Day 18) you will guess in production. Don't.

Caveats

  • 1Model and version churn. Names quoted here reflect the May 2026 landscape; expect changes every 60–90 days. Anchor learning on APIs and patterns (Responses API, Messages API, MCP), not specific model strings.
  • 2Frameworks overlap heavily. Pick one orchestration framework (recommend LangGraph) and master it. The marginal value drops fast after the third.
  • 3Pricing volatility. Per-token prices, free-tier limits, and grounding/web-search charges change frequently. Always verify against the vendor pricing page the week you build.
  • 4Preview vs. GA status. AWS Bedrock AgentCore, Foundry Hosted Agents, A2A protocol versions, and several Vertex AI services were in preview as of May 2026. Do not bet production SLAs on preview features without enterprise-tier support agreements.
  • 515 hrs/day is unsustainable for most humans for 30 days. A more realistic schedule is 8–10 hrs/day for 45–60 days with the same content. Treat the 450-hour budget as the content, not necessarily the calendar.
  • 6The 80/20 stack is not neutral. It biases toward Python, Anthropic/OpenAI, Microsoft/Azure, and LangChain. Engineers in JS-heavy, GCP-native, or open-source-only shops should swap the relevant days.
  • 7Beads and agentic-coding hooks have small user bases. Treat them as productivity multipliers, not load-bearing production dependencies.
  • 8This roadmap intentionally underweights classical ML. Supplement with Designing Machine Learning Systems (Huyen) and a separate MLOps track if your team does heavy tabular ML, fine-tuning, or model training.
